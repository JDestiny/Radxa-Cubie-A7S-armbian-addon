# 厂商组件获取

本仓库不含三个大体积组件（GPU 内核驱动源码、GPU 用户态库、NPU AI SDK）。它们都来自板卡厂商的
官方发布物，请按下表取得并放进对应目录，然后再运行各组件目录里的安装脚本。

放好之后目录应该长这样：

```
gpu/img-bxm-dkms-src/          # GPU 内核驱动源码（原版，IMG 的 DKMS 包源码）
gpu/img-bxm-dkms-src-gpuacct/  # 同上，但打上 GPU 利用率记账补丁（+gpuacct 变体）
gpu/userspace/                 # GPU 用户态：EGL/GLES/Vulkan/OpenCL 库 + rgx.fw 固件 + ICD
npu/ai-sdk/                    # NPU 中间件与运行时（vpm_run / libVIPhal 等）
```

---

## 一、GPU 内核驱动源码与用户态

两者都来自 **Radxa 官方 Cubie A7S 镜像**（Debian bullseye，含 KDE 桌面）：

1. 从 Radxa 文档的下载页取得镜像（`radxa-a733_bullseye_kde_r6.output_512.img.xz`，
   约 500 MB）：<https://docs.radxa.com/en/cubie/a7s/download>
2. 解压并挂载：

```bash
xz -d radxa-a733_bullseye_kde_r6.output_512.img.xz
sudo losetup -Pf --show radxa-a733_bullseye_kde_r6.output_512.img    # 记下输出的 /dev/loopX
sudo mkdir -p /mnt/r6 && sudo mount -o ro /dev/loopXp2 /mnt/r6       # p2 一般是 rootfs（ext4）
```

3. **用户态库与固件** → `gpu/userspace/`

```bash
# 按镜像内实际路径为准；下面用 find 先定位，再整目录拷出
sudo find /mnt/r6 -name 'libGLESv2.so*' -o -name 'libVK_IMG.so*' -o -name 'rgx.fw' | head
sudo mkdir -p gpu/userspace
sudo cp -a /mnt/r6/usr/lib/aarch64-linux-gnu/lib{EGL,GLESv1_CM,GLESv2,gbm,glapi,vulkan}*.so* gpu/userspace/ 2>/dev/null
sudo cp -a /mnt/r6/usr/lib/aarch64-linux-gnu/dri gpu/userspace/ 2>/dev/null      # 含 swrast_dri.so / sunxi-drm_dri.so
sudo find /mnt/r6/lib/firmware -iname 'rgx*' -exec sudo cp -a {} gpu/userspace/ \;
```

> 具体文件名随镜像版本略有差异；`install-gpu-userspace.sh` 会按它认识的布局去安装，
> 缺文件时会把缺的那一项报出来，照提示补即可。

4. **内核驱动源码** → `gpu/img-bxm-dkms-src/`

镜像里以 DKMS 包（`img-bxm-dkms`，版本形如 `0.1.0-3`）分发，源码在包内或
`/usr/src/img-bxm-dkms-*` 下：

```bash
sudo find /mnt/r6 -maxdepth 6 -name '*img-bxm*' | head        # 找到 deb 或已安装的源码目录
sudo cp -a /mnt/r6/usr/src/img-bxm-dkms-*/ gpu/img-bxm-dkms-src/
```

`gpu/img-bxm-dkms-src-gpuacct/` 是同一份源码加上 GPU 利用率记账补丁（用于在 `htop` 里看到
GPU 使用率）。补丁由本项目维护，如需从零构建：先复制原版目录，再按 `gpu/README.md`
的说明应用补丁；也可以直接使用本项目的 Release 附件（若提供）。

> 卸载镜像：`sudo umount /mnt/r6 && sudo losetup -d /dev/loopX`

## 二、NPU AI SDK

来自 Radxa 官方文档为 Cubie A7S 指定的 AI SDK 仓库（与 `github.com/ZIFENG278/ai-sdk` 同源）：

```bash
git clone --depth 1 https://github.com/ZIFENG278/ai-sdk npu/ai-sdk
```

克隆后确认 `npu/ai-sdk/` 下能看到 `vpm_run`、`libVIPhal.so` 等文件，然后运行：

```bash
cd npu && sudo ./install-npu.sh
```

> SDK 约 800 MB（含模型与例程）；如官方仓库地址有更新，以 Radxa 文档 NPU 页面的链接为准。

## 三、VE（视频编解码）

**不需要另外获取**：`ve/usr-lib/`（18 个库）与 `ve/include/`（头文件）已随本仓库提供，
执行 `ve/install-ve.sh` 即可安装。
